# Pathway step tips

`Hints.lua` holds short location notes for quest steps ("Talk to Wiley the Black upstairs",
"Enter the Troll cave") and short how-to notes for objectives ("Kill Defias Thugs. Loot them
for Bandanas"), shown in the current step in Pathway's guide.

text was trimmed and re-keyed by quest and position. Generated by `tools/hints.py`.
